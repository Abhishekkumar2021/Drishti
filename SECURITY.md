# Security Policy

## Supported Versions

We actively support and patch the latest version of Drishti. If you discover a security issue, please ensure you are running the latest release before submitting a report.

| Version | Supported |
| ------- | --------- |
| v0.1.x  | ✅ Yes     |
| < v0.1.0| ❌ No      |

## Reporting a Vulnerability

We take the security of Drishti seriously. If you find a security vulnerability, please do **not** open a public GitHub issue. Instead, report it privately to the maintainer:

* **Email:** [abhishek.kumar2021@gmail.com](mailto:abhishek.kumar2021@gmail.com)
* Please include as much detail as possible, including:
  - A description of the vulnerability.
  - Steps to reproduce (a proof-of-concept script/exploit is highly appreciated).
  - Potential impact of the vulnerability.

## Our Security Commitment

If you submit a security report, we commit to:
1. **Acknowledge** receipt of the report within **48 hours**.
2. **Investigate** and verify the vulnerability.
3. **Provide a timeline** for fixing the issue.
4. **Coordinate a release** containing the fix, and attribute credit to you (if desired) in the changelog/release notes.

Thank you for helping keep Drishti secure!
